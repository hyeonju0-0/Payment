# Payment

메뉴를 고르고 현금 또는 계좌이체로 주문하는 웹 프로그램입니다. 계좌번호는 계좌이체를 선택했을 때만 표시됩니다. 주문은 구글 스프레드시트에 기록됩니다. 관리자는 입금 완료, 수령 완료, 환불 상태를 바꿀 수 있고, 주문을 직접 추가할 수도 있습니다.

## 실행

Node.js가 설치되어 있어야 합니다.

```bash
npm start
```

서버가 켜진 동안 브라우저에서 아래 주소로 엽니다.

- 주문 화면: http://127.0.0.1:3000
- 관리자 화면: http://127.0.0.1:3000/admin

`npm start`는 서버만 실행합니다. 화면은 위 주소를 브라우저에 입력해야 열립니다.

## 주문

1. 메뉴를 장바구니에 담고 주문자 이름을 입력합니다. 소스는 여러 개 고를 수 있습니다.
2. 결제하기에서 현금 또는 계좌이체를 고릅니다.
3. 계좌이체면 계좌번호가 열리고, 복사 버튼으로 복사할 수 있습니다.
4. 주문 내용은 구글 스프레드시트에 기록됩니다.

## 관리자

- 입금 대기, 입금 완료, 수령 완료, 환불 상태를 바꿀 수 있습니다. 실제 송금은 처리하지 않고 상태만 바뀝니다.
- 주문 추가로 이름, 메뉴, 소스, 결제 방법을 넣어 주문을 직접 등록할 수 있습니다.
- 관리자 화면은 이 컴퓨터에서 서버를 켠 뒤 http://127.0.0.1:3000/admin 에서 비밀번호를 입력해 엽니다.

## 설정

가게 이름, 계좌, 메뉴는 `config.js`에서 바꿉니다. 서버를 다시 시작해야 이 컴퓨터의 화면에 반영됩니다. 공개 주문 페이지는 `public` 폴더를 배포해야 바뀝니다.
